# 모니터링

허브의 알림이 모이는 곳이다. SNS 주제 `<prefix>-alerts`를 두고, 확인용 SQS 수신함 `<prefix>-alerts-inbox`가 그 주제를 구독한다. `alert_email`을 주면 메일도 구독한다. 지금은 알림 주제와 수신함만 있고, 알람은 아직 없다.

## 개념도에서의 위치

"모니터링" 상자다. ⑩ "기록 수집"과 ⑪ "이상 탐지 알림"의 자리이고, 지금은 ⑪의 알림 주제만 만든다. 호스팅 심사가 실패할 때(④-1 "심사 실패 알림")도 이 주제로 알린다.

## 파일

| 파일 | 역할 |
|---|---|
| `terraform/` | SNS 주제, SQS 수신함과 그 접근 정책, 구독(SQS, 고르면 메일). 내보내는 값은 `topic_arn`. |
